# Librarian's Bargain v1.0.2-mc26.1.2

## Changes

- Bargaining and rerolling no longer consume Diamonds.
- Accepting a final offer costs 7 Diamonds.
- Bargain attempts can be rejected at 5%, 15%, or 25% depending on active locks.
- Rejected attempts keep the current proposal list unchanged.
- Three rejected attempts forcibly close the bargaining screen.
- Rejection feedback now uses a sharp anvil sound.
- Proposal acceptance tooltips track the mouse more closely.
- The bargaining screen closes after a proposal is accepted.
- The Mysterious Contract recipe is now 1 Book and Quill + 1 Emerald + 1 Blaze Rod.
- Fixed the mod name apostrophe rendering.

## Compatibility

- Minecraft 26.1.2
- NeoForge 26.1.2.97+
- Java 25
